# XZX Fishing Macro

Standalone fishing macro (no AutoHotkey). The Windows `.exe` is built in the cloud by
GitHub Actions — you don't need Python installed.

## Get the .exe
1. Go to the **Actions** tab → **Build Fishing EXE** → **Run workflow**.
2. When it finishes (a minute or two), open the run and download the **XZX-Fishing-exe** artifact.
3. Unzip it and run **XZX Fishing.exe** as administrator.

Editing `fishing-macro/fishing_macro.py` and pushing also triggers a build automatically.
